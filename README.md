# ONLY PLAY · 只有声音的美术馆

> 一座局域网里的音乐美术馆:上传 MP3 与 LRC 即入藏,打开即播、歌词同步,白天 / 夜间双展厅。

ONLY PLAY 是一个**单用户、零配置**的局域网音乐播放器。它把自己想象成一座美术馆——歌曲是展品,封面是画框,歌词是展签,而你是唯一的观众。

- 🖼 **展厅** —— 沉浸式播放页,逐行高亮的同步歌词,点击任意一行即可跳转
- 📚 **曲库** —— 所有藏品的目录,点选即播;编辑模式支持全选 / 多选、批量移除
- 🎨 **入藏** —— 拖入 `.mp3` / `.lrc`,同名自动配对
- 🖌 **补封面** —— 无内嵌封面的曲目自动从 QQ 音乐 / iTunes / 网易云检索官方专辑图,宁缺毋滥
- 🖼 **选封面** —— 点行首小封面或展厅大封面,从 QQ 音乐 / iTunes / 网易云的候选中挑选,或直接上传图片;替换同样适用
- 🎵 **播放列表** —— 底部播放栏一键展开抽屉式队列,当前曲高亮、点击即切播;进入专辑播放时即为专辑内循环
- 🌗 **白天 / 夜间** —— 双主题展厅,跟随系统、记忆选择

## 功能特性

- **网页拖放入藏**:MP3 与 LRC 一次拖入,按文件名自动配对;未匹配的歌词进入「待配对」列表,可手动指派给任意曲目
- **元数据自动读取**:标题、艺术家、专辑、时长、内嵌封面自动解析([music-metadata](https://github.com/borewit/music-metadata));缺失时从「艺术家 - 标题.mp3」文件名反解
- **封面自动补全**:无内嵌封面的曲目入藏后在后台自动联网补图——依次查 QQ 音乐(半官方接口,官方专辑图)、iTunes Search API(官方、免密钥)、网易云(非官方接口,失效时自动跳过),三路按最近命中自适应排序;检索结果须与曲目的艺术家 / 标题对得上才采用,对不上就留白,绝不张冠李戴。曲库页的「补封面」按钮可随时给存量曲目批量补全并重试未匹配项
- **同步歌词**:支持标准 LRC,逐行高亮、点击跳转
- **流式播放**:音频接口支持 HTTP Range,进度条可随意拖动
- **状态记忆**:刷新即回到原界面——曲目、播放进度、播放中状态、所在页面(含专辑详情与曲库列表模式)全部保留;首次使用进入「专辑」页;歌曲播完自动下一首
- **快捷键**:`空格` 播放 / 暂停,`←` / `→` 快退 / 快进 5 秒
- **纯文件存储**:所有数据落在 `data/` 目录,备份即拷贝,无数据库依赖

## 快速开始

要求 Node.js ≥ 18。

```bash
git clone git@github.com:wolfpan/onlyplay.git
cd onlyplay
npm install
npm start
```

打开 <http://localhost:3000> 即恢复上次的界面与播放进度;首次使用会进入「专辑」页。若浏览器拦截了自动播放,任意点击一次即可续播。

局域网 / VPN 内其他设备访问 `http://<本机IP>:3000`。

### 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |

Windows PowerShell 自定义端口:

```powershell
$env:PORT=8080; npm start
```

## 使用指南

**入藏**:进入「入藏」页,把 `.mp3` 与 `.lrc` 拖入(或点击选择),同名文件自动配对。单文件上限 200MB,一次最多 100 个。未被匹配的歌词会留在「待配对歌词」列表中,手动指派给任意曲目即可。

**展厅**:右上角圆形图标切换白天 / 夜间展厅,选择会被记忆。点击任意歌词行可跳转到该句。

**曲库**:点击曲目即播放,点击行首小封面可挑选封面;点「编辑」进入多选模式,工具栏提供「补封面」(给所有缺封面的曲目批量联网补图,按钮上显示进度,此前未匹配到的也会重试)与「全选 / 移除」,移除需二次确认,`Esc` 退出编辑。

**播放列表**:点击底部播放栏的列表图标展开抽屉,展示当前播放顺序(进入专辑播放时即该专辑曲目,并标注「专辑内循环」),当前曲高亮、点击任意一曲即切播;`Esc`、关闭按钮或点击抽屉外任意处收起。

**选封面**:点击曲库行首的小封面(或展厅里的大封面)打开「选择封面」——聚合 QQ 音乐 / iTunes / 网易云三路候选,精确匹配置前、未精确匹配半透明标注,点击候选即设为封面;也可在弹窗右下角直接上传本地图片。已封面曲目同样适用(即更换封面)。

**备份**:所有数据存于 `data/`(`songs.json` 索引 + `music/` 音频 + `lyrics/` 歌词 + `covers/` 封面),备份即拷贝整个目录。

## 项目结构

```
onlyplay/
├── server.js          # Express 服务:上传、音频流、歌词、封面补全、曲库 API
├── lib/
│   ├── library.js     # 曲库:文件系统 + songs.json 索引,入藏 / 配对 / 移除
│   ├── cover-fetch.js # 封面自动补全:iTunes + 网易云检索,限速队列
│   └── lrc.js         # LRC 歌词解析
├── public/            # 前端(原生 HTML / CSS / JS,无构建步骤)
│   ├── index.html
│   ├── app.js
│   └── style.css
└── data/              # 运行时生成,不入库
    ├── songs.json     # 曲目索引
    ├── music/         # 音频文件
    ├── lyrics/        # LRC 歌词
    └── covers/        # 提取的封面
```

## 技术栈

- 后端:Node.js(ESM)+ Express + Multer + music-metadata
- 前端:原生 HTML / CSS / JavaScript,零依赖、零构建

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/songs` | 曲库全量(曲目 + 待配对歌词) |
| POST | `/api/upload` | 上传 MP3 / LRC(multipart,字段 `files`) |
| GET | `/audio/:id` | 音频流(支持 Range) |
| GET | `/api/cover/:id` | 曲目封面 |
| GET | `/api/lyrics/:id` | 解析后的歌词行 |
| POST | `/api/songs/:id/pair` | 手动配对歌词,body:`{ "lrcId": number }` |
| POST | `/api/covers/fetch` | 触发封面补全,body 可选 `{ "ids": [number] }`,省略即全部缺封面曲目 |
| GET | `/api/covers/status` | 封面补全队列进度 |
| GET | `/api/covers/search/:id` | 手动选封面:聚合三源候选(不落库) |
| POST | `/api/songs/:id/cover` | 应用封面:multipart 图片字段 `file`,或 JSON `{ "url": string }` |
| DELETE | `/api/songs` | 批量移除,body:`{ "ids": [number] }` |
| DELETE | `/api/songs/:id` | 移除曲目 |
| DELETE | `/api/lyrics/:lrcId` | 移除待配对歌词 |

## 安全提示

ONLY PLAY 按单用户设计,**没有任何鉴权**:任何能访问该端口的人都可以上传、删除你的曲库。请仅在局域网 / VPN 内使用,不要将端口暴露到公网。
